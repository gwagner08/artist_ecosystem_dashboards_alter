# Firebird logo

The official red wordmark is already here as `firebird-wordmark.png`.

Accepted filenames, in the order the header tries them:

    web/public/brand/firebird-wordmark.svg     (preferred - scales cleanly)
    web/public/brand/firebird-wordmark.png     (in use)
    web/public/firebird-wordmark.png           (also picked up)

For the dark theme, add the official **white** wordmark as
`firebird-wordmark-white.svg` (or `.png`) and it is used automatically.

The header picks it up automatically and hides the slot if the file is absent, so
nothing breaks while it's missing.

Get the file from the team Drive folder "Firebird and Portco Branding":
https://drive.google.com/drive/folders/1WXkXPNC-rgE2_CoyUagpysvvc2yl1-nG

- Red wordmark (secondary logo):
  https://drive.google.com/file/d/1XUKv5EthIEqBeYfU-e_FGkLE7ItC1wfh/view
- White wordmark, for the dark theme, saved as `firebird-wordmark-white.svg`:
  https://drive.google.com/file/d/1XR8IJ06Cq2Sd0uM_bPLI01_yULUqNvzc/view

Use the official files as-is. Per brand guidelines the logo is never redrawn,
recoloured, outlined or distorted — which is why this app ships an empty slot
rather than an approximation.
